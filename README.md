# Nanda Shein Downloader 🚀

High-Performance 1080P Social Media Video Downloader Web Application.

Download high-definition videos without watermarks from TikTok, Facebook, Instagram Reels, YouTube Shorts, X (Twitter), and more.

## ✨ Features

- **1080P Full HD Downloads:** Download social videos in crisp 1080P 60fps quality.
- **No Watermark:** Clean, watermark-free video downloads for TikTok & Instagram Reels.
- **Multi-Platform Support:** TikTok, Facebook, Instagram, YouTube Shorts, X (Twitter), Threads, Pinterest.
- **In-App Video Player:** High-definition video player with speed control and picture-in-picture.
- **Audio Extractor:** Convert and download background music / sound as 320kbps MP3.
- **Batch Downloader:** Parse and download multiple links concurrently.
- **Bilingual Interface:** Seamless Myanmar (မြန်မာ) & English language toggle.
- **Modern Responsive Web Design:** Optimized for both mobile smartphones and desktop widescreen.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend:** Node.js, Express, tsx
- **Build Tool:** Vite

## 🚀 Quick Start

```bash
# 1. Clone repository
git clone https://github.com/<your-username>/nanda-shein-downloader.git
cd nanda-shein-downloader

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open `http://localhost:3000` in your browser.
